# Hi, I'm Mateusz 👋

I build backend systems and the infrastructure that keeps them running.

Most of my work sits where code meets operations: APIs, CI/CD pipelines, observability, and Linux boxes that need to stay up. Lately I've been writing more Go and Rust aiming toward some open-source contributions.

I write about what I learn at [kiersnowski.dev](https://kiersnowski.dev).

### What I work on

- ⚙️ **Backend**: Python (FastAPI), Go, Rust services and APIs
- 🐧 **Linux**: daily driver, dotfiles, tinkering close to the system
- 🚀 **DevOps**: CI/CD, containers, infrastructure as code
- 📈 **Observability**: Prometheus, Grafana, Tempo, metrics and tracing
- 💡 **Startups**: validating ideas fast by building full-stack MVPs, with my focus on the infra, backend and DevOps side
